# Política de privacidade — Editor para GP-200

Última atualização: 29 de outubro de 2026.

Esta política se aplica ao aplicativo Android "Editor para GP-200" (pacote `io.github.marcosepifanio.gp200editor`), um projeto independente e de código aberto mantido por João Marcos Epifanio. O aplicativo não é um produto oficial da Valeton e não tem vínculo, afiliação ou endosso da fabricante.

## Resumo

O aplicativo não coleta, não envia e não compartilha dados pessoais. Ele não tem acesso à internet, não usa contas, anúncios, análise de uso nem relatórios de falha de terceiros.

## Dados que ficam no aparelho

Para funcionar, o aplicativo guarda localmente, no armazenamento privado do próprio app:

- a cópia dos presets lidos da pedaleira e seus nomes, para exibir a biblioteca sem uma nova leitura completa;
- a lista de efeitos marcados como favoritos;
- arquivos `.prst` temporários criados quando você escolhe compartilhar um preset.

Esses dados não saem do aparelho por iniciativa do aplicativo. Eles são apagados quando você limpa os dados do app ou o desinstala.

## Comunicação com a pedaleira

O aplicativo se comunica com a pedaleira apenas por cabo USB, usando a API MIDI do Android. As mensagens trocadas contêm configurações de presets, efeitos, controles e ritmos da pedaleira, e não são enviadas a nenhum servidor.

## Arquivos que você abre ou exporta

Ao importar um arquivo `.prst`, o aplicativo lê somente o arquivo que você escolheu. Ao exportar ou compartilhar, o arquivo vai para o local ou para o aplicativo que você selecionou; a partir daí, ele segue as regras desse local ou aplicativo.

## Backup do Android

Se o backup do Android estiver ativado no aparelho, o sistema pode incluir os dados locais do aplicativo no backup da sua conta Google. Esse backup é feito pelo Android, segue as configurações e os termos do Google, e o mantenedor do aplicativo não tem acesso a ele. Você pode desativá-lo nas configurações de backup do aparelho.

## Links externos

A tela "Sobre" tem links para páginas de projetos no GitHub. Eles só são abertos no navegador quando você os toca; a partir daí, valem as políticas do site visitado.

## Crianças

O aplicativo não é direcionado a crianças e não coleta dados de nenhum usuário.

## Alterações

Mudanças nesta política serão publicadas nesta página, com a data de atualização revisada.
